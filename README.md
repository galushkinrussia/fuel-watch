# FuelWatch — монитор появления бензина на АЗС

Следит за живыми отметками водителей (данные `gdebenz.ru`, открытый JSON-эндпоинт)
и уведомляет, когда на выбранных заправках появляется топливо.

Два варианта:

| Вариант | Что делает | Где запускать | Push на телефон |
|---|---|---|---|
| `monitor/` (Python) | опрашивает API, шлёт push | любой сервер / ПК / домашний NAS | через **ntfy.sh** (Android-приложение) или Telegram |
| `android/` (Kotlin) | фоновый сервис опрашивает API прямо на телефоне | сам телефон | локальные уведомления Android |

---

## 1. Python-монитор (работает сразу)

Требуется только Python 3 (без сторонних библиотек).

### Посмотреть текущее наличие

```bash
python3 monitor/fuel_watch.py list --lat 48.680 --lon 44.470 --radius 8 --fuel 92 95 ДТ
```

### Следить и получать push (ntfy.sh)

1. Установите на телефон приложение **ntfy** (Google Play / F-Droid).
2. В приложении подпишитесь на тему, например `volga-fuel-mike` (любое уникальное имя).
3. Запустите монитор:

```bash
python3 monitor/fuel_watch.py watch \
  --lat 48.680 --lon 44.470 --radius 8 \
  --fuel 92 95 \
  --topic volga-fuel-mike \
  --interval 180
```

Когда на АЗС в радиусе появится АИ-92/95 (переход «нет → есть/очередь»),
на телефон придёт push-уведомление вида:

> ⛽ Бензин появился
> Лукойл · ул. Неждановой, 4Б
> 92, 95
> Очередь 100+ машин

Первый опрос фиксирует текущее состояние без уведомлений (база), дальше —
только изменения. Состояние сохраняется в `state.json`, переживает перезапуск.

### Через конфиг-файл

```bash
cp monitor/config.example.json monitor/config.json   # отредактируйте
python3 monitor/fuel_watch.py watch --config monitor/config.json
```

### Опционально: уведомления в Telegram

Создайте бота у `@BotFather`, узнайте `chat_id` (`@userinfobot`) и добавьте:

```bash
python3 monitor/fuel_watch.py watch --lat 48.680 --lon 44.470 --fuel 92 95 \
  --tg-token 123456:ABC... --tg-chat 123456789
```

### Запуск в фоне

```bash
nohup python3 monitor/fuel_watch.py watch --config monitor/config.json > monitor.log 2>&1 &
```

## 2. Облако (GitHub Actions) — работает 24/7 без вашего компьютера

Монитор крутится на GitHub бесплатно, push на телефон через ntfy.sh.

### Шаги

1. Создайте аккаунт на [github.com](https://github.com) и новый репозиторий.
2. Загрузите проект в репозиторий:

```bash
cd ~/fuel-watch
git init -b main
git add .
git commit -m "init"
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
git push -u origin main
```

3. В репозитории откройте **Settings → Secrets and variables → Actions → Variables**
   и добавьте переменные:

   | Переменная | Пример значения |
   |---|---|
   | `LAT` | `48.680` |
   | `LON` | `44.470` |
   | `RADIUS` | `8` |
   | `FUEL` | `92 95` |
   | `TOPIC` | `volga-fuel-mike` |

4. Откройте вкладку **Actions** и включите рабочие процессы.
5. Проверьте вручную: **Actions → fuel-monitor → Run workflow**.

Готово — теперь опрос идёт каждые 15 минут, состояние запоминается между
запусками (файл `state.json`), а при появлении бензина push приходит в ntfy
на телефон и в браузере.

### Ограничение бесплатного тарифа

- **Публичный репозиторий** — GitHub Actions бесплатен без лимита минут;
  можно оставить `*/15` или даже `*/5`.
- **Приватный репозиторий** — лимит ~2000 мин/мес. Каждые 15 мин ≈ 2900 мин/мес
  (чуть выше лимита), поэтому в `fuel-monitor.yml` поменяйте cron на
  `*/30 * * * *` (каждые 30 минут).

> Если репозиторий публичный, а тему ntfy не хотите светить — включите у неё
> пароль: на `https://ntfy.sh/<тема>` нажмите «Settings» → задайте access token,
> а в телефоне при подписке укажите его же.

## 3. Android-приложение (Kotlin)

Полностью автономное: фоновый сервис (`MonitorService`) опрашивает тот же API
прямо с телефона и показывает локальные уведомления. Бэкенд и Firebase не нужны.

### Сборка

1. Откройте папку `android/` в **Android Studio** (проект с Gradle).
2. Дождитесь синхронизации (AGP 8.3.2 / Kotlin 1.9.23 / compileSdk 34).
3. Запустите на устройстве: **Build → Build APK(s)**.

### Использование

1. Введите координаты (по умолчанию — Ворошиловский район Волгограда),
   радиус и интервал опроса.
2. Отметьте нужные марки (АИ-92, АИ-95, АИ-98, АИ-100, ДТ).
3. Нажмите **Старт** — разрешите уведомления (Android 13+).
4. Приложение шлёт push, когда на АЗС появляется выбранное топливо.

Пояснение статусов: `yes` = есть, `queue` = есть, но очередь, `no` = нет.

---

## Как устроен источник данных

Эндпоинт: `https://gdebenz.ru/api/nearby?lat=…&lon=…&radius_km=…&full=1`

Возвращает JSON со списком АЗС, у каждой:
`status` (`no`/`queue`/`yes`), `fuels_now` (например `"92,95,ДТ"`), `detail`
(«Очередь 100+ машин · Лимит 40 л»), `last_at` (время отметки), `distance_km`.

Данные — отметки самих водителей, поэтому актуальность не гарантируется;
проверяйте на месте.

---

## Важно

- Это справочные, краудсорсинговые данные, а не оферта заправок.
- Не злоупотребляйте частотой опроса (интервал 3–5 мин разумен).
- Если `gdebenz.ru` недоступен, есть запасной адрес `gdebenz.org`.
